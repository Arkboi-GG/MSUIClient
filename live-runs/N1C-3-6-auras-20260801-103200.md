# NIGHT_01C 3-6 — auras, buffs, and debuffs

Status: `CLOSED-PASS`

## Instrument-before-fix finding

The first live self-buff run exposed the server's legal packet order: it sent
`SMSG_UPDATE_AURA_DURATION` for slot 1 immediately before the object descriptor
replaced that slot's previous spell with Power Word: Fortitude. A spell-keyed
timer therefore attached 30 minutes to the outgoing Greater Invisibility and
left Fortitude untimed.

## Increment

- Added build-5875 `SMSG_UPDATE_AURA_DURATION` (`0x0137`) handling and
  `CMSG_CANCEL_AURA` (`0x0136`) encoding by spell id, with golden byte checks.
- Added `spell-aura` verdict/CSV rows for apply, remove, stack, duration,
  cancel-send, and cancel-blocked, including helpful/cancelable/display state.
- Fixed duration ownership to be slot-keyed and preserve the timer across a
  same-update slot replacement, matching the observed server ordering.
- Added player countdown text, stack counts, and right-click cancellation for
  cancelable buffs. Debuffs remain visible on the target plate with their stack
  counts; noncancelable/debuff cancellation is mechanically refused.
- Added reusable lifecycle replay commands covering a timed stacked buff and a
  stacked debuff.

## Mechanical result

- The final protocol passed 33/33. The synthetic matrix emitted APPLY,
  120000-ms DURATION, three-stack STACK, cancelable CANCEL_SEND, REMOVE, then a
  two-stack debuff with CANCEL_BLOCKED and REMOVE.
- With GM off, learned Power Word: Fortitude passed its Z0 self-cast gate at
  1000 mana / 60 cost. The server returned START and GO, applied the aura, and
  supplied a 1,800,000-ms timer before the same-slot descriptor replacement.
  The fixed APPLY row carries that timer.
- `CMSG_CANCEL_AURA` flushed with the exact four-byte little-endian spell id;
  the server removed the aura 83 ms later. Descriptor checks passed present
  before cancellation and absent afterward.
- The server exposed no help entry for `aura` or `unaura`, so neither unverified
  GM command was used. The already-verified `.learn` command plus a real
  GM-off cast supplied the acceptance state instead.
